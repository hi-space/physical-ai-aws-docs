# 5. GPU Workflow Verification

Run a simple `nvidia-smi` workflow to verify that the entire pipeline works correctly. If this test succeeds:
- OSMO CLI → OSMO Service → Backend Operator → Pod creation path is functional
- Kai Scheduler correctly allocates GPU resources
- NVIDIA RuntimeClass nvidia properly injects GPU drivers into containers
- ctrl sidecar correctly reports workflow status

---

### 5.1 Scale Up GPU Nodes

GPU node groups are configured with 0 nodes to minimize costs. Manually scale up one node before running workflows:

```bash
aws eks update-nodegroup-config \
  --cluster-name osmo-eks \
  --nodegroup-name gpu-train \
  --scaling-config minSize=0,maxSize=4,desiredSize=1 \
  --region us-west-2
```

Wait 2-3 minutes for the node to reach Ready state:

```bash
# Use -w to watch real-time status changes
kubectl get nodes -l node-role=gpu-train -w
```

Press Ctrl+C when `STATUS` changes to `Ready`.

---

### 5.2 Submit GPU Test Workflow

OSMO workflows are defined in YAML. Run a simple GPU workflow:

```bash
cat > /tmp/gpu-test.yaml <<'EOF'
workflow:
  name: gpu-test
  resources:
    default:
      cpu: 4
      gpu: 1
      memory: 8Gi
      storage: 10Gi
      platform: gpu-train
  tasks:
  - name: gpu-check
    image: nvidia/cuda:12.8.0-base-ubuntu22.04
    command: ["nvidia-smi"]
EOF

osmo workflow submit /tmp/gpu-test.yaml
```

{% hint style="info" %}
`platform: gpu-train` references the GPU platform defined in step 4.4.
{% endhint %}

---

### 5.3 Verify Results

```bash
# Check workflow status (repeat until COMPLETED)
osmo workflow query gpu-test-1

# Check logs — should show nvidia-smi output
osmo workflow logs gpu-test-1
```

**Expected output:**

```
Workflow ID : gpu-test-1
Status      : COMPLETED

Task Name    Start Time               Status
=============================================
gpu-check    ...                      COMPLETED
```

Check GPU information in logs:

```
NVIDIA L40S | Driver: 570.x | CUDA: 12.8 | 46068MiB
```

{% hint style="warning" %}
**Troubleshooting:** If stuck in `SCHEDULING` state, GPU nodes are not yet Ready. Verify with `kubectl get nodes -l node-role=gpu-train`.
{% endhint %}

### Troubleshooting

| Symptom | Cause | Solution |
|---------|-------|----------|
| Pod stuck in `SCHEDULING` | No GPU nodes (count = 0) | Scale up in step 5.1 |
| `QueueDoesNotExist` | Kai Queue not created | [Step 4.5 in 4. OSMO Configuration](4.-osmo-config.md) |
| Image pull failed | NGC secret not created | [Step 3.5 in 3. OSMO Installation](3.-osmo-install.md) |
