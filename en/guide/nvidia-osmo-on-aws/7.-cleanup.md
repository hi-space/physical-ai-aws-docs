# 7. Cleanup

After completing the workshop, delete resources to avoid incurring costs.

---

### 7.1 Delete OSMO Helm Releases

```bash
helm uninstall osmo-minimal -n osmo-minimal
helm uninstall osmo-operator -n osmo-operator
helm uninstall kai-scheduler -n kai-scheduler
```

---

### 7.2 Delete Namespaces

```bash
kubectl delete namespace osmo-minimal osmo-operator osmo-workflows kai-scheduler
```

---

### 7.3 Clean Up IAM Resources

```bash
# Delete Access Key
ACCESS_KEY_ID=$(aws iam list-access-keys --user-name osmo-workflow-user \
  --query 'AccessKeyMetadata[0].AccessKeyId' --output text)
aws iam delete-access-key --user-name osmo-workflow-user --access-key-id $ACCESS_KEY_ID

# Delete Policy
aws iam delete-user-policy --user-name osmo-workflow-user --policy-name osmo-s3-access

# Delete User
aws iam delete-user --user-name osmo-workflow-user
```

---

### 7.4 Delete CDK Stack

```bash
cd ~/aws-physical-ai-recipes/osmo/cdk
npx cdk destroy --context region=us-west-2
```

{% hint style="info" %}
CDK destroy takes approximately 15 minutes. EKS cluster deletion takes the longest.
{% endhint %}

---

### 7.5 Verify Deletion

```bash
# Verify CloudFormation stack is deleted
aws cloudformation describe-stacks --stack-name Osmo --region us-west-2 2>&1 | grep -q "does not exist" && echo "Deletion complete"
```

{% hint style="warning" %}
If `cdk destroy` fails, manually delete the stack in AWS Console → CloudFormation. Deletion may fail if the S3 bucket is not empty. Empty the bucket first, then retry.
{% endhint %}
