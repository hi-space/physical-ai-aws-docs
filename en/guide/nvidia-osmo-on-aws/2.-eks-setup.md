# 2. Kubernetes Setup

Install the basic components required to run GPU workloads on your EKS cluster. Kubernetes does not natively recognize GPUs, so NVIDIA plugins must be installed.

---

### 2.1 kubeconfig Configuration

Configure `kubectl` to communicate with your EKS cluster:

```bash
aws eks update-kubeconfig --name osmo-eks --region us-west-2
kubectl get nodes
```

**Expected output (Two system nodes in Ready state):**

```
NAME                                       STATUS   ROLES    AGE   VERSION
ip-10-0-1-xxx.us-west-2.compute.internal   Ready    <none>   5m    v1.30.x
ip-10-0-3-xxx.us-west-2.compute.internal   Ready    <none>   5m    v1.30.x
```

{% hint style="info" %}
Seeing only two system nodes is normal. GPU nodes are manually scaled up before running workflows.
{% endhint %}

---

### 2.2 NVIDIA Device Plugin Installation

**Why is this needed?** By default, Kubernetes only manages CPU and memory. To recognize GPUs as allocatable resources and assign them to Pods, the NVIDIA Device Plugin is required. With this plugin installed, you can request resources like `nvidia.com/gpu: 1`.

```bash
kubectl apply -f https://raw.githubusercontent.com/NVIDIA/k8s-device-plugin/v0.14.5/nvidia-device-plugin.yml
```

Verify:

```bash
kubectl get daemonset -n kube-system nvidia-device-plugin-daemonset
```

---

### 2.3 NVIDIA RuntimeClass Creation

**Why is this needed?** To run `nvidia-smi` or use CUDA inside containers, the container runtime must mount the host's GPU drivers into the container. Specifying `nvidia` as the RuntimeClass automatically enables this mounting.

```bash
kubectl apply -f - <<'EOF'
apiVersion: node.k8s.io/v1
kind: RuntimeClass
metadata:
  name: nvidia
handler: nvidia
EOF
```

Verify:

```bash
kubectl get runtimeclass nvidia
```

### Troubleshooting

| Symptom | Cause | Solution |
|---------|-------|----------|
| `error: You must be logged in` | kubeconfig not configured or insufficient permissions | Rerun `aws eks update-kubeconfig` |
| NVIDIA Device Plugin not running | No GPU nodes present | Normal. Runs automatically when GPU nodes scale up |
| `RuntimeClass nvidia not found` | RuntimeClass not created | Run step 2.3 |
