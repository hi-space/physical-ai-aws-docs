# 7. Resource Cleanup

Delete all infrastructure with CDK after the workshop. Leaving resources running incurs Head Node and FSx charges.

{% hint style="info" %}
Commands in this document use the `${USER_ID}` environment variable. In a new shell session, first run:
```bash
export USER_ID=<your_name>   # Same value from Step 1
```
{% endhint %}

---

### 7.1 Cancel Running Jobs

```bash
# On Head Node, check running jobs
squeue

# Cancel all user jobs
scancel --user=ubuntu
```

---

### 7.2 Delete CDK Stack (~20 minutes)

From CloudShell or local machine:

```bash
cd ~/aws-physical-ai-recipes/hyperpod-training/infra

npx cdk destroy -c userId=${USER_ID} -c region=us-east-1 --force
```

---

### 7.3 Troubleshoot Deletion

Stack deletion may fail if S3 buckets aren't empty:

```bash
# Empty buckets
aws s3 rm s3://hyperpod-lifecycle-hyperpod-${USER_ID}-<ACCOUNT_ID>-us-east-1 --recursive
aws s3 rm s3://hyperpod-data-hyperpod-${USER_ID}-<ACCOUNT_ID>-us-east-1 --recursive

# Retry stack deletion
aws cloudformation delete-stack \
  --stack-name HyperPod-${USER_ID} \
  --region us-east-1
```

---

### 7.4 Verify Deletion

```bash
aws cloudformation describe-stacks \
  --stack-name HyperPod-${USER_ID} \
  --region us-east-1 2>&1

# Output "Stack with id HyperPod-${USER_ID} does not exist" confirms successful deletion
```
