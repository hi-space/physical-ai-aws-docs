## 5.1 Isaac Lab Environment Setup

Isaac Lab is an RL framework built on NVIDIA Isaac Sim, enabling thousands of parallel simulation environments with GPU acceleration.

### Environment Installation (First Time Only)

```bash
# Install Isaac Lab environment (container import + workshop task setup, ~15 minutes)
bash /fsx/scratch/aws-physical-ai-recipes/hyperpod-training/scripts/setup_isaaclab_env.sh
```

This script:
- Imports Isaac Sim container from NGC and converts to Enroot image (`/fsx/enroot/data/isaaclab+latest.sqsh`, ~20GB)
- Copies workshop SO-101 task package to `/fsx/scratch/isaaclab-workshop/`
- Creates checkpoint and log directories

To manually import container only:
```bash
mkdir -p /fsx/enroot/data /fsx/enroot/tmp
export ENROOT_CACHE_PATH=/fsx/enroot
export ENROOT_DATA_PATH=/fsx/enroot/data
export TMPDIR=/fsx/enroot/tmp

sudo enroot import --output /fsx/enroot/data/isaaclab+latest.sqsh \
  docker://nvcr.io#nvidia/isaac-sim:4.5.0
```

{% hint style="info" %}
Isaac Sim container is ~20GB. Storing on FSx makes it available to all compute nodes.
{% endhint %}

### Available Workshop Tasks

| `Workshop-SO101-Reach-v0` | Move end-effector to random target | Easy | ~15 min |

## 5.2 Run RL Training

### Submit SLURM Job

```bash
# Submit Reach task training (default, ~15 min)
sbatch /fsx/scratch/aws-physical-ai-recipes/hyperpod-training/slurm-templates/rl/finetune_isaaclab.sbatch

# Lift task training
TASK=Workshop-SO101-Lift-v0 MAX_ITERATIONS=500 \
  sbatch /fsx/scratch/aws-physical-ai-recipes/hyperpod-training/slurm-templates/rl/finetune_isaaclab.sbatch
```

### Using Wrapper Script

```bash
/fsx/scratch/aws-physical-ai-recipes/hyperpod-training/slurm-templates/rl/run_rl.sh \
  --task Workshop-SO101-Reach-v0 --iterations 300
```

### Training Parameters

| Variable | Default | Description |
|------|--------|------|
| `TASK` | Workshop-SO101-Reach-v0 | Isaac Lab task ID |
| `NUM_ENVS` | 2048 | Parallel simulations (proportional to VRAM) |
| `MAX_ITERATIONS` | 300 | PPO training iterations |
| `LOG_DIR` | /fsx/checkpoints/rl | Checkpoint save location |
| `CHECKPOINT` | (none) | Resume checkpoint path |

### Verify Trained Policy in Simulation

Test if the trained RL policy successfully completes tasks in simulation.

{% hint style="warning" %}
Head node lacks GPU, so always allocate GPU nodes via `srun`.
{% endhint %}

```bash
# Allocate interactive GPU shell
srun --partition=dev --gres=gpu:1 --time=00:30:00 --pty bash

# Run headless evaluation in Enroot container
sudo enroot start --root --rw --rc /fsx/scratch/isaaclab_rc.sh \
  --mount /fsx:/fsx \
  --env ACCEPT_EULA=Y --env PRIVACY_CONSENT=Y \
  --env NVIDIA_VISIBLE_DEVICES=all \
  --env DISPLAY="" \
  --env PYTHONPATH="/fsx/scratch/IsaacLab/source/isaaclab_rl:/fsx/scratch/isaaclab-workshop/src:/fsx/scratch/IsaacLab/source/isaaclab_tasks" \
  isaaclab \
  python3 /fsx/scratch/aws-physical-ai-recipes/hyperpod-training/examples/rl/train_isaaclab.py \
    --task Workshop-SO101-Reach-v0 \
    --checkpoint /fsx/checkpoints/rl/reach/SO101_Reach/model_300.pt \
    --num_envs 256 \
    --max_iterations 0 \
    --headless
```

## 5.5 Troubleshooting

| Symptom | Cause | Solution |
|------|------|----------|
| Container image not found | Enroot image not created | Re-run `enroot import` |
| CUDA OOM with 2048 envs | A10G VRAM insufficient | Reduce `NUM_ENVS=1024` or `512` |
| `ModuleNotFoundError: workshop` | Task package not registered | Add workshop path to `sys.path` |
| `--headless` flag ignored | Isaac Sim version mismatch | Force headless with `DISPLAY=""` environment variable |
| Training not converging | Insufficient iterations | Increase `MAX_ITERATIONS=1000` |
