# 3. Data Preparation

This section prepares the SO101 place-orange dataset for GR00T N1.6 fine-tuning. Download data from HuggingFace, upload to S3, and FSx Data Repository Association automatically syncs it to the cluster.

{% hint style="info" %}
Commands in this document use the `${USER_ID}` environment variable. In a new shell session, first run:
```bash
export USER_ID=<your_name>   # Same value from Step 1
```
{% endhint %}

---

## FSx for Lustre and Data Repository Association

**FSx for Lustre** is AWS's high-throughput parallel file system designed for ML workloads:

- **High throughput**: Hundreds of GB/s throughput for fast read/write of massive datasets
- **Parallel I/O**: Multiple nodes can simultaneously access the same file (POSIX-compliant)
- **Shared storage**: Head Node and all compute nodes access `/fsx/` identically

**Data Repository Association (DRA)** automates S3-FSx sync:

- **Auto-import**: Files uploaded to S3 automatically sync to FSx
- **Auto-export**: Checkpoints created on FSx automatically back up to S3
- **Background operation**: Sync progresses without impacting training

```
Local/CloudShell → S3 upload → FSx (DRA auto-sync) → Training on compute node
```

## 3.1 Dataset Introduction: SO101 Place Orange

This workshop uses the [LightwheelAI/so101-place-orange](https://huggingface.co/datasets/LightwheelAI/so101-place-orange) dataset.

| Item | Value |
|------|-----|
| Robot | SO101 follower (6-DOF) |
| Task | "place orange on the plate" |
| Episodes | 61 |
| Camera | front + wrist (480×640, 30fps) |
| Format | LeRobot v2 |
| Size | ~788MB |

**Joint configuration (6-DOF):**
- shoulder_pan, shoulder_lift, elbow_flex, wrist_flex, wrist_roll, gripper

**Dataset structure:**
```
so101-place-orange/
├── meta/
│   ├── info.json          # fps=30, robot_type=so101_follower
│   ├── episodes.jsonl     # 61 episode metadata
│   └── tasks.jsonl        # "place orange on the plate"
├── data/chunk-000/
│   └── episode_000000.parquet  # action(6-DOF), observation.state(6-DOF)
└── videos/chunk-000/
    ├── observation.images.front/episode_000000.mp4
    └── observation.images.wrist/episode_000000.mp4
```

## 3.2 Download Dataset and Upload to S3

Download the dataset from your local machine or CloudShell, then upload to S3.

### Verify S3 Bucket Name

```bash
# Check S3BucketName from CDK deployment outputs
BUCKET=$(aws cloudformation describe-stacks \
  --stack-name HyperPod-${USER_ID} \
  --region us-east-1 \
  --query "Stacks[0].Outputs[?OutputKey=='S3BucketName'].OutputValue" \
  --output text)

echo "S3 Bucket: ${BUCKET}"
```

### Download from HuggingFace → Upload to S3

```bash
# Install huggingface_hub (CloudShell or local)
pip install -U "huggingface_hub[cli]"

# Download dataset
hf download LightwheelAI/so101-place-orange \
  --repo-type dataset \
  --local-dir ./so101-place-orange

# Upload to S3
aws s3 sync ./so101-place-orange s3://${BUCKET}/datasets/groot/so101-place-orange/ --quiet
```

{% hint style="info" %}
Dataset is approximately 788MB. Uploading from CloudShell uses internal AWS networks, so it's fast.
{% endhint %}

## 3.3 Verify FSx Sync

After uploading to S3, FSx auto-syncs within minutes. On Head Node, verify:

```bash
# Head Node (after SSH)
ls /fsx/datasets/groot/so101-place-orange/
```

**Expected output:**
```
data  meta  videos
```

If not yet synced, wait a moment and check again (usually 1-3 minutes).

## 3.4 Validate Data

Verify the dataset is in correct LeRobot v2 format:

```bash
source /fsx/envs/gr00t/bin/activate

python3 /fsx/scratch/aws-physical-ai-recipes/hyperpod-training/examples/vla/prepare_dataset.py \
  --dataset-path /fsx/datasets/groot/so101-place-orange \
  --validate
```

**Expected output:**
```
Dataset: /fsx/datasets/groot/so101-place-orange
Validating LeRobot v2 format...
  ✓ All checks passed
  Episodes: 61
  Data shards: 1
  Video files: 122
```

## 3.5 Training Readiness Check

```bash
# Check dataset size
du -sh /fsx/datasets/groot/so101-place-orange/

# Check FSx free space
df -h /fsx/
```

Once the dataset is correctly prepared at `/fsx/datasets/groot/so101-place-orange/`, proceed to the next step.
